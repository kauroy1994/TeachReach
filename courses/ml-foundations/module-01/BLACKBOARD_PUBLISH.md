# Blackboard publishing — Machine Learning Foundations, Module 01

1. Add a Blackboard **Web Link** titled **TeachReach — Module 01: Slides, Exercises & Office Hours**.
2. Set its URL to `https://kauroy1994.github.io/TeachReach/courses/ml-foundations/module-01/`.
3. Students can open the slides, tensor exploration lab, exercises, and faculty-curated virtual office hours in any browser.
4. Questions are sent to Prof. Roy by email from the **Ask a New Question** tab; no student LLM account is needed.
5. To publish a reviewed answer for everyone, edit `assets/faq_seed.js` through GitHub, then refresh the site.

The same root TeachReach website will support future modules in sibling folders. Exercise progress is stored locally in each student's browser and is not sent to Blackboard.
