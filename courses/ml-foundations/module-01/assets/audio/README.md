# TeachReach · FAQ audio recordings

Every approved FAQ has an `id` in `../faq_seed.js`.

Record your own spoken explanation in `faculty-recordings.html` and save the file to this directory as `<faq-id>.webm`.

For example: `faq-vector.webm`. The public office-hours player discovers files automatically.

No browser speech synthesis is used. For text-to-speech voice clones, use only a verified clone of the professor's authorized voice and publish the resulting audio to the same filenames.
