MACHINE LEARNING FOUNDATIONS · MODULE 02

From predictions to probabilities.

In Module 1, we learned to compute a score from tensors. Now we ask a harder question: How certain should we be about that score? Follow Ava and the Campus Study Coach from one numerical prediction to probabilistic modeling.

Probability will become a learning objective.
