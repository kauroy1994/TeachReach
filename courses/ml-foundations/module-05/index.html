Regression and Classification

Learning predictions from data. Linear regression, least squares, Gaussian likelihood, logistic regression, sigmoid, binary cross-entropy, and parameter estimation.

What should the prediction look like?

A rule awards 5 points per completed set plus 40 starting points. Three sets give 55. Predicting an exam score asks for a number. Predicting whether someone passes asks for a probability of one of two outcomes.

WHAT YOU'LL LEARN

Module learning outcomes

  • Fit and interpret regression and classification parameters.
  • Relate least squares and cross-entropy to likelihood.
  • Evaluate predictions using suitable task metrics.
LEARNING SEQUENCE

How this lesson builds

  1. Plot two input–score pairs on paper. A line gives a predicted score at each input. Draw the vertical difference to the observed score and square it.
  2. Add the squared errors over the training rows. With fixed Gaussian spread, smaller squared error also gives smaller negative log-likelihood. Apply the update from Module 03.
  3. Encode pass as 1 and fail as 0. Introduce a sigmoid as a curve taking any input score to a number between 0 and 1. A score of zero maps to probability 0.5.
  4. For a true pass, compare predicted probabilities 0.8 and 0.2. Taking minus the log penalizes the second prediction more. Include the corresponding failure case to build binary cross-entropy.

MODULE 05 · PRACTICE AND IN-CLASS ASSESSMENT

Practice and in-class assessment

Try it on paper

A rule awards 5 points per completed set plus 40 starting points. Three sets give 55. Predicting an exam score asks for a number. Predicting whether someone passes asks for a probability of one of two outcomes.

A student’s observed score is 61 and the rule predicts 58. What is the squared error? If the target is pass/fail, what else must you specify?

Hint

Subtract before squaring. Then decide how a score becomes a label.

Reveal answerHide answer

The squared error is (58 − 61)² = 9. Specify the passing threshold to label the outcome and a probability model to predict a pass.

Practice exercise directions

  • Derive and fit a regression model on a small dataset.
  • Calculate classification probabilities and cross-entropy.
