Let nearby examples vote

WHAT YOU'LL LEARN

Module learning outcomes

  • Compare neighborhood, partition, and margin-based decision rules.
  • Compute a tree split or nearest-neighbor prediction.
  • Explain model complexity and the effect of an ensemble.
LEARNING SEQUENCE

How this lesson builds

  1. Measure one-dimensional distance by counting units, then find the distance between two points on a grid. Choose k examples with the smallest distances and count their class votes.
  2. Split a table at one threshold and count labels on each side. A tree chooses questions that leave purer groups. Use those counts to introduce entropy and information gain.
  3. Draw two possible separating lines and measure the gap to the nearest training points. This distance motivates the margin used by a support-vector machine.
  4. Let several trees vote, then compare with adding a second small tree to correct earlier errors. Check all rules on held-out points.

MODULE 06 · PRACTICE AND IN-CLASS ASSESSMENT

Practice and in-class assessment

Try it on paper

On a number line, examples at 1 and 3 have label A and the example at 8 has label B. The new point 4 is one unit from 3, three from 1 and four from 8. Its closest example votes A.

A new point is 7 on the same number line. Which label wins with one neighbor? What about three?

Hint

Order the locations by distance from 7.

Reveal answerHide answer

The closest point is 8, so one neighbor predicts B. With all three neighbors, A wins two votes to one.

Practice exercise directions

  • Make and justify a prediction using kNN or tree splitting.
  • Compare inductive biases of multiple algorithms.
