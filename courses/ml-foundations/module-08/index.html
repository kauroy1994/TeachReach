What can a second computation add?

WHAT YOU'LL LEARN

Module learning outcomes

  • Compute a forward pass through a small network.
  • Trace parameter gradients with the chain rule.
  • Train and compare a small network with a linear baseline.
LEARNING SEQUENCE

How this lesson builds

  1. Draw a one-input linear rule and evaluate it at two values. Label the arrow with its weight and the output with its bias.
  2. Apply max(0, z) after the weighted sum. Name it ReLU, an activation. Inspect the positive and negative regions before composing units.
  3. Use one unit’s output as another unit’s input. Follow one example forward, then multiply local slopes backward along the same arrows. Sum contributions where a parameter has several paths.
  4. Build the same small network in PyTorch. Compare its predictions and held-out loss with a linear baseline.

MODULE 08 · PRACTICE AND IN-CLASS ASSESSMENT

What exercises will assess

Try it on paper

A unit computes 2x − 3 and passes positive values through while replacing negative values with zero. At x = 1 it outputs 0. At x = 3 it outputs 3. This bend lets a network represent a change in slope.

A hidden unit outputs max(0, 2x − 3). A second unit multiplies its output by 4. What does the network return at x = 2?

Hint

Complete the hidden calculation first.

Reveal answerHide answer

2 × 2 − 3 = 1, which passes through the activation. The second unit gives 4 × 1 = 4.
