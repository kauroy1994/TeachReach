How can a hidden unit learn if there is no label for it?

The prediction loss depends on the hidden value. The chain rule measures how changing the hidden unit’s weight changes that final loss. Updating the weight lets the final label guide the intermediate feature.

What does backward() actually change?

It traverses the recorded computation and accumulates derivatives in each trainable parameter’s .grad field. An optimizer step changes the parameter values. Clearing old gradients before the next batch prevents accidental accumulation across updates.

Does a ReLU output of zero mean the entire network has stopped learning?

A single inactive unit supplies zero input-weight gradient from that example along that path. Other examples may activate it. Other units or the output bias can receive gradients from the same example.

Why use a known formula as the target when we could just calculate it?

A known target lets us separate what the model family can express from ambiguity in labels. We can verify every prediction and locate a limitation of a straight line. Real applications require a separate reason to estimate an unknown rule from examples.
