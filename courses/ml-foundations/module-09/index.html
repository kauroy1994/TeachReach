Deep Learning and Representation Learning

What can a small filter detect?

Move the two-number filter [−1, 1] along a brightness row [2, 2, 7]. Its outputs are 0 and 5. The large response locates an increase in brightness. The output row is a new representation.

WHAT YOU'LL LEARN

Module learning outcomes

  • Explain how depth changes the functions a model can express.
  • Implement a small deep network and inspect intermediate features.
  • Recognize vanishing gradients and the purpose of residual connections.
LEARNING SEQUENCE

How this lesson builds

  1. Slide one fixed filter across a short row, multiplying and summing at each position. Identify the meaning of a positive or zero response.
  2. Repeat across an image patch and stack the resulting maps. Later filters can combine nearby changes into larger patterns. Show where training supplies the filter weights.
  3. Follow a product of slopes such as 0.5 × 0.5 × 0.5 to see why signals can shrink with depth. Add a direct path that passes its input onward alongside the learned change.
  4. Compare training traces with and without that path. Introduce normalization by centering and scaling activations and inspect intermediate maps on new images.

MODULE 09 · PRACTICE AND IN-CLASS ASSESSMENT

Practice and in-class assessment

Try it on paper

Move the two-number filter [−1, 1] along a brightness row [2, 2, 7]. Its outputs are 0 and 5. The large response locates an increase in brightness. The output row is a new representation.

Using the same filter on [7, 7, 4], what two values appear and what does the second mean?

Hint

The response equals right minus left in each window.

Reveal answerHide answer

The responses are 0 and −3. The second pair gets darker by three units.
