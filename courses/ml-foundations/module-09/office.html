What makes an intermediate number a feature?

Its role in the next computation. The filter output 2 describes a local rise and becomes input to a later unit. The same number could be a final answer in a task that asks only for the size of that rise.

Does every hidden neuron have a name people can recognize?

We chose filter weights that expose a simple pattern. Learned features can mix several patterns, and changing units together can preserve a network’s predictions. Inspect responses to controlled input changes before assigning an interpretation.

Will adding more layers always improve my results?

Depth can reuse and compose features. Useful performance also depends on data, optimization and evaluation. Compare depths with the same train/validation split, inspect losses and record whether performance on new records improves.

How is input scaling related to normalization inside a network?

Both put numbers on a useful scale. Here we fixed training-set statistics for an input feature. A layer such as LayerNorm instead computes statistics across specified features of each input example. The axes and the moment when statistics are computed matter.
