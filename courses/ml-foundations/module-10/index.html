STAGE 3 · MODULE 10 · SYLLABUS PREVIEW

Self-Supervised Learning and Embeddings

Learning useful signals without hand-labeling everything. Pretext tasks, contrastive learning, positive/negative pairs, embedding spaces, similarity, reconstruction, and pretraining.

WHAT YOU'LL LEARN

Learning outcomes

  • Describe a self-supervised objective and the information it uses.
  • Implement a simple contrastive or reconstruction-based task.
  • Evaluate embeddings with similarity and downstream probes.
HOW THIS MODULE IS TAUGHT

The same learning pattern as Modules 01–02

  1. Review the required foundations from earlier modules.
  2. See a real-world problem and interact with its visualization.
  3. Derive the mathematical operation and implement it in PyTorch.
  4. Practice until ready for the instructor's end-of-module in-class variant.
