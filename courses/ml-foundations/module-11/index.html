WHAT YOU'LL LEARN

Learning outcomes

  • Compute attention weights from small query/key matrices.
  • Explain causal masks and positional information.
  • Implement a minimal attention layer in PyTorch.
HOW THIS MODULE IS TAUGHT

How this lesson builds

  1. Write a sentence as an ordered list of tokens. Give each token a vector and mark its position so rearranging the words can change the representation.
  2. Give the current token a query vector and each candidate a key vector. Compute their dot products as match scores. Scale the scores, exponentiate and divide by their sum to obtain attention weights.
  3. Multiply each value vector by its weight and add. In a next-token task, mask future positions before normalization so their weights are zero.
  4. Run two independently learned sets of queries, keys and values as two heads. Identify attention, the feed-forward layer and the residual paths in a small transformer block.
Every module includes practice exercises.

MODULE 11 · EXERCISES

Practice and in-class assessment

Try it on paper

Suppose two earlier tokens carry values 2 and 8. If the current token gives them weights ¼ and ¾, it receives ¼ × 2 + ¾ × 8 = 6.5. This is the value-mixing step of attention.

Two accessible values are 2 and 8. Before applying a mask their weights are equal. If the second is a future token and must be masked, what is the mixed value?

Hint

Renormalize across the positions still available.

Reveal answerHide answer

Only the first value remains, so its weight is 1 and the mixture is 2.

Learning skills assessed

  • Calculate scaled dot-product attention for small tensors.
  • Explain how a mask changes accessible context.

MODULE 11 · NOTEBOOK

Python warm-up

Mix two values using different weights.

for weight in [0.25, 0.5, 0.75]:
    print((1 - weight) * 2 + weight * 8)

What will the code print, and why?

Reveal answerHide answer

3.5, 5.0 and 6.5. More weight on 8 pulls the output toward 8.
