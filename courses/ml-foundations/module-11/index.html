STAGE 3 · MODULE 11 · SYLLABUS PREVIEW

Sequence Modeling, Attention, and Transformers

Learning relationships across a sequence. Sequence representations, positional information, queries/keys/values, dot-product attention, masking, multi-head attention, and transformer blocks.

Assessment requirements

WHAT YOU'LL LEARN

Learning outcomes

  • Compute attention weights from small query/key matrices.
  • Explain causal masks and positional information.
  • Implement a minimal attention layer in PyTorch.
HOW THIS MODULE IS TAUGHT

The same learning pattern as Modules 01–02

  1. Review the required foundations from earlier modules.
  2. See a real-world problem and interact with its visualization.
  3. Derive the mathematical operation and implement it in PyTorch.
  4. Practice until ready for the instructor's end-of-module in-class variant.
