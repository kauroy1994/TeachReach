Why do we need values when we already have keys?

An item can match a question by color and contribute information about brightness. Separate projections let the model learn which coordinates determine a match and which coordinates to send once matched.

Why do we need both position information and a mask?

Position information gives the model a way to distinguish locations. A causal mask enforces a visibility rule. A position vector alone would still let a next-token predictor read a later token.

Does a high attention weight explain the entire prediction?

It describes one mixture at one head and layer. The size and direction of the value vector, other heads, later layers and residual paths also affect the prediction.
