WHAT YOU'LL LEARN

Learning outcomes

  • Contrast likelihood-based, adversarial, and denoising generation.
  • Describe the encoder–latent–decoder computation in a VAE.
  • Implement and interpret a simple noise-and-denoising sequence.
HOW THIS MODULE IS TAUGHT

How this lesson builds

  1. Start by drawing new numbers from a known distribution. Ask what must be learned to draw examples resembling a training collection.
  2. Encode an example as a distribution over a short hidden vector, sample the vector, and decode a reconstruction. For a variational autoencoder, balance reconstruction with keeping the hidden distribution near a chosen prior.
  3. Compare with a generator that proposes samples and a discriminator that learns to distinguish proposed from observed examples. Trace which model receives each training signal.
  4. Add known noise in stages and train a predictor to recover it. Walk backward through a few illustrative steps before discussing diffusion schedules and sampling.
Every module includes practice exercises.

MODULE 13 · EXERCISES

Practice and in-class assessment

Try it on paper

Add a noise value of +2 to a clean measurement of 5 to obtain 7. A model that predicts noise +1.5 would estimate a clean value of 5.5 by subtraction. This is one denoising example.

A noisy value is 9 and a model estimates added noise of +3. In this simple additive example, what is its clean estimate? Which training target is available if we added the noise ourselves?

Hint

Reverse addition with subtraction.

Reveal answerHide answer

The estimate is 9 − 3 = 6. We know the injected noise and can compare the model’s noise prediction with it.

Learning skills assessed

  • Explain a VAE or GAN training objective at a conceptual/mathematical level.
  • Reason about diffusion steps and generation limitations.

MODULE 13 · NOTEBOOK

Python warm-up

Subtract each noise estimate from the noisy value 7.

for estimate in [1.5, 2.0]:
    print(7 - estimate)

What will the code print, and why?

Reveal answerHide answer

5.5 and 5.0. The estimate of 2 recovers the original measurement exactly.
