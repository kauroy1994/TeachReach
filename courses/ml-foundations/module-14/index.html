STAGE 4 · MODULE 14 · SYLLABUS PREVIEW

Reinforcement Learning and Sequential Decision-Making

Learning to act through rewards. Markov decision processes, states/actions/rewards, policies, value functions, Bellman updates, exploration, and Q-learning.

WHAT YOU'LL LEARN

Learning outcomes

  • Formulate a small sequential decision problem as an MDP.
  • Compute value estimates using Bellman updates.
  • Explain exploration versus exploitation and delayed reward.
HOW THIS MODULE IS TAUGHT

The same learning pattern as Modules 01–02

  1. Review the required foundations from earlier modules.
  2. See a real-world problem and interact with its visualization.
  3. Derive the mathematical operation and implement it in PyTorch.
  4. Practice until ready for the instructor's end-of-module in-class variant.
