WHAT YOU'LL LEARN

Learning outcomes

  • Formulate a small sequential decision problem as an MDP.
  • Compute value estimates using Bellman updates.
  • Explain exploration versus exploitation and delayed reward.
HOW THIS MODULE IS TAUGHT

How this lesson builds

  1. Draw two locations and the moves between them. Name a location a state and a move an action. Record immediate rewards separately from rewards still to come.
  2. Add rewards along one path, multiplying later rewards by a discount factor. Average returns over possible paths to explain the value of a state or action.
  3. Write today’s estimate as immediate reward plus discounted estimated future value. Compute a Bellman backup with two successors, then apply the same arithmetic in a small grid.
  4. Use sampled transitions to update an action value toward a target. Compare taking the action with the highest estimate with trying an uncertain action to learn more.

MODULE 14 · EXERCISES

Practice and in-class assessment

Try it on paper

In a two-step game, a move earns 0 now and 4 on the next move. If future rewards count half as much per step, the return today is 0 + 0.5 × 4 = 2.

A move gives reward 1 now and leads to a state with estimated value 6. With discount 0.5, what is the one-step target?

Hint

Keep the immediate reward at full weight.

Reveal answerHide answer

1 + 0.5 × 6 = 4. The 6 describes estimated future return starting at the next state.

Learning skills assessed

  • Compute a Bellman backup on an unfamiliar state.
  • Choose and explain an action-selection policy.

MODULE 14 · NOTEBOOK

Python warm-up

Compare how much a later reward counts.

for discount in [0.0, 0.5, 1.0]:
    print(0 + discount * 4)

What will the code print, and why?

Reveal answerHide answer

0, 2 and 4. A larger discount factor gives more weight to the later reward.
