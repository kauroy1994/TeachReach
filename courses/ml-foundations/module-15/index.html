Does 80% confidence mean what it says?

A model assigns 80% confidence to ten predictions. Six are correct. In this small group the observed accuracy is 60%, a 20-percentage-point gap. Another group could give a different estimate.

WHAT YOU'LL LEARN

Learning outcomes

  • Diagnose overconfidence and evaluate calibration.
  • Design basic robustness and distribution-shift tests.
  • Interpret explanations while distinguishing association from causation.
HOW THIS MODULE IS TAUGHT

How this lesson builds

  1. Group predictions with similar confidence and count the fraction correct in each group. Plot confidence against accuracy to introduce a reliability diagram.
  2. Keep the model fixed and change one property of a test input. Measure performance under small perturbations and after a change in the population being sampled.
  3. Compare errors across groups using denominators and sample sizes. Ask which differences are stable enough to investigate and which need more data.
  4. Inspect how a prediction changes when one feature changes. Explain what this shows about the model and what additional evidence a causal claim would require.

MODULE 15 · EXERCISES

Practice and in-class assessment

Try it on paper

A model assigns 80% confidence to ten predictions. Six are correct. In this small group the observed accuracy is 60%, a 20-percentage-point gap. Another group could give a different estimate.

In a held-out group of 50 predictions made at 80% confidence, 40 are correct. What is the gap in that group? Does it establish calibration everywhere?

Hint

Compare 40/50 with 0.80.

Reveal answerHide answer

The observed gap is zero in that group. Other confidence levels, populations and sample sizes still need evaluation.

Learning skills assessed

  • Find an overconfident model from calibration evidence.
  • Interpret a stress-test failure and recommend a check.

Python warm-up

confidence = 0.8

What will the code print, and why?
