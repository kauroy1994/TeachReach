STAGE 4 · MODULE 15 · SYLLABUS PREVIEW

Trustworthy ML: Uncertainty, Robustness, and Interpretability

Knowing when not to trust a model. Calibration, confidence versus uncertainty, robustness, distribution shift, fairness-aware evaluation, interpretability, and stress testing.

WHAT YOU'LL LEARN

Learning outcomes

  • Diagnose overconfidence and evaluate calibration.
  • Design basic robustness and distribution-shift tests.
  • Interpret explanations while distinguishing association from causation.
HOW THIS MODULE IS TAUGHT

The same learning pattern as Modules 01–02

  1. Review the required foundations from earlier modules.
  2. See a real-world problem and interact with its visualization.
  3. Derive the mathematical operation and implement it in PyTorch.
  4. Practice until ready for the instructor's end-of-module in-class variant.
