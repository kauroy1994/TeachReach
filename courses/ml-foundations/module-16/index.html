WHAT YOU'LL LEARN

Learning outcomes

  • Design a reproducible ML experiment with baselines.
  • Implement and compare models using appropriate metrics.
  • Defend conclusions, assumptions, limitations, and reliability evidence.
HOW THIS MODULE IS TAUGHT

How this lesson builds

  1. Choose a small question, define each input and target, and choose the metric before comparing results. Identify a simple baseline another student can reproduce by hand.
  2. Freeze the data split. Fit on the training set, use validation data for choices and evaluate the final comparison on the reserved test set.
  3. Report an aggregate score and inspect individual errors or groups. Include one case in which the baseline wins and explain what evidence might distinguish competing explanations.
  4. Give a classmate the split, code, model settings and random seed. Have them reproduce the comparison and defend a conclusion limited to the evidence collected.
Every module includes practice exercises.
The graded variant is administered separately in class, at the end of Module 16.

MODULE 16 · EXERCISES

Practice and in-class assessment

Try it on paper

On three held-out examples a constant baseline has absolute errors [2, 4, 3]; a candidate has [1, 1, 4]. Their mean absolute errors are 3 and 2. One example still favors the baseline.

Using the three errors above, which example got worse, by how much, and what would you inspect before claiming the candidate is more reliable?

Hint

Pair the errors row by row.

Reveal answerHide answer

The third error grew from 3 to 4, an increase of 1. Inspect that case and compare more held-out cases, including relevant groups, before making a broad claim.

Learning skills assessed

  • Defend a model choice and evaluation design.
  • Interpret unseen-data results and propose a justified improvement.
