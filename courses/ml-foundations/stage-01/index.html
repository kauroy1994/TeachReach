STAGE 1 OUTCOMES

By the end of this stage, you can…

  • Represent observations and parameters with tensors and matrix operations.
  • Model uncertainty using distributions, conditional probability, and likelihood.
  • Derive gradients and formulate optimization objectives.
  • Explain empirical risk, estimation, hypothesis classes, and generalization.
Stage milestone: Build the mathematical language needed for every subsequent learning algorithm.
ASSESSMENT THROUGHOUT THE STAGE

Learn, practice, demonstrate.

  1. Read each module's worked explanation and complete its interactive exercises.
  2. Use feedback and the module notebook to understand why the methods work.
  3. At the end of every module, complete a new in-class variant of the exercises administered and graded by the instructor.

Published practice is not the graded variant. Assessment topics and methods are listed on each module page.

MODULE 01 · STAGE 1

Linear Algebra and Tensor Operations

From observations to numerical predictions

Lessons available

Vectors, matrices, tensor axes, shapes, indexing, broadcasting, transformations, and a parameterized prediction rule.

Learning outcomes

  • Construct feature vectors and dataset matrices with correct shapes.
  • Compute predictions using matrix products and broadcasting.
  • Explain tensor ranks and representations with PyTorch.

Practice & in-class assessment

Module practice will target: Tensor shape explorer; Study Coach prediction calculator.

The instructor-administered, graded in-class variant at this module's end assesses equivalent skills:

  • Determine shapes and valid operations for unfamiliar observations.
  • Calculate and explain predictions from a given feature matrix.
Class slides, interactive lab, practice exercises, notebook, and Office Hours are available.Open learning module →
MODULE 02 · STAGE 1

Probability and Probabilistic Modeling

From point predictions to uncertainty

Lessons available

Random variables, PMFs, PDFs, CDFs, expectation, variance, conditioning, Bayes, likelihood, and distribution fitting.

Learning outcomes

  • Compute probabilities from discrete and continuous distributions.
  • Update beliefs using conditional probability and Bayes’ rule.
  • Evaluate and fit probabilistic models using likelihood.

Practice & in-class assessment

Module practice will target: Normal-distribution slider; Bayes and conditional-probability lab.

The instructor-administered, graded in-class variant at this module's end assesses equivalent skills:

  • Calculate an event probability and explain the denominator.
  • Update a posterior and interpret an estimated distribution.
Class slides, interactive lab, practice exercises, notebook, and Office Hours are available.Open learning module →
MODULE 03 · STAGE 1

Calculus, Gradients, and Optimization

From a loss value to parameter updates

Syllabus preview

Functions, derivatives, partial derivatives, gradients, chain rule, critical points, gradient descent, learning rates, and autograd.

Learning outcomes

  • Derive gradients of simple machine-learning objectives.
  • Trace the chain rule through composed computations.
  • Implement and troubleshoot gradient descent in PyTorch.

Practice & in-class assessment

Module practice will target: Gradient vector field and loss surface; Learning-rate and optimizer-step comparison.

The instructor-administered, graded in-class variant at this module's end assesses equivalent skills:

  • Compute a gradient and one update from fresh numerical values.
  • Diagnose convergence behavior under different learning rates.

MODULE 04 · STAGE 1

Statistical Learning, Estimation, and Generalization

What does it mean to learn from examples?

Syllabus preview

Population versus sample, hypothesis classes, expected risk, empirical risk, estimation, inductive bias, train/test distinction, and generalization.

Learning outcomes

  • Distinguish population objectives from empirical objectives.
  • Describe sampling variation and assumptions of a hypothesis class.
  • Recognize data leakage, inductive bias, and poor generalization.

Practice & in-class assessment

Module practice will target: Empirical-risk versus population-risk simulator; Sampling and estimation explorer.

The instructor-administered, graded in-class variant at this module's end assesses equivalent skills:

  • Formulate an empirical-risk objective for a stated task.
  • Identify a flawed sampling or evaluation design.
