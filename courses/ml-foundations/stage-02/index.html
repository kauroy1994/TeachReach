STAGE 2 OUTCOMES

By the end of this stage, you can…

  • Derive and implement regression and classification objectives.
  • Compare distance-based, tree-based, ensemble, and margin-based approaches.
  • Discover structure in unlabeled data using clustering and dimension reduction.
  • Train and explain a small neural network with backpropagation.
Stage milestone: Implement several model families and justify their selection with evidence.
ASSESSMENT THROUGHOUT THE STAGE

Learn, practice, demonstrate.

  1. Read each module's worked explanation and complete its interactive exercises.
  2. Use feedback and the module notebook to understand why the methods work.
  3. At the end of every module, complete a new in-class variant of the exercises administered and graded by the instructor.

Published practice is not the graded variant. Assessment topics and methods are listed on each module page.

MODULE 05 · STAGE 2

Regression and Classification

Learning predictions from data

Syllabus preview

Linear regression, least squares, Gaussian likelihood, logistic regression, sigmoid, binary cross-entropy, and parameter estimation.

Learning outcomes

  • Fit and interpret regression and classification parameters.
  • Relate least squares and cross-entropy to likelihood.
  • Evaluate predictions using suitable task metrics.

Practice & in-class assessment

Module practice will target: Fit a regression line to data; Move a probabilistic decision boundary.

The instructor-administered, graded in-class variant at this module's end assesses equivalent skills:

  • Derive and fit a regression model on a small dataset.
  • Calculate classification probabilities and cross-entropy.

MODULE 06 · STAGE 2

Classical ML: kNN, Trees, SVMs, and Ensembles

Different ways to carve up a decision space

Syllabus preview

Distance and similarity, k-nearest neighbors, information gain, decision trees, ensembles, boosting intuition, margins, and support-vector machines.

Learning outcomes

  • Compare neighborhood, partition, and margin-based decision rules.
  • Compute a tree split or nearest-neighbor prediction.
  • Explain model complexity and the effect of an ensemble.

Practice & in-class assessment

Module practice will target: kNN and tree decision-boundary explorer; Margin and ensemble comparison.

The instructor-administered, graded in-class variant at this module's end assesses equivalent skills:

  • Make and justify a prediction using kNN or tree splitting.
  • Compare inductive biases of multiple algorithms.

MODULE 07 · STAGE 2

Unsupervised Learning, Clustering, and PCA

Discovering patterns without labels

Syllabus preview

Distance, k-means, cluster assignments, covariance, eigenvectors, principal components, Gaussian mixtures, and latent structure.

Learning outcomes

  • Run and interpret k-means.
  • Explain PCA as maximizing retained variance.
  • Contrast hard clusters with probabilistic assignments.

Practice & in-class assessment

Module practice will target: Move k-means centers; Rotate a PCA projection.

The instructor-administered, graded in-class variant at this module's end assesses equivalent skills:

  • Perform a k-means assignment or update step.
  • Identify a principal direction and discuss limitations.

MODULE 08 · STAGE 2

Neural Networks and Backpropagation

Beyond one linear transformation

Syllabus preview

Perceptrons, nonlinear activations, multilayer perceptrons, computational graphs, forward passes, chain rule, and backpropagation.

Learning outcomes

  • Compute a forward pass through a small network.
  • Trace parameter gradients with the chain rule.
  • Train and compare a small network with a linear baseline.

Practice & in-class assessment

Module practice will target: Activation-function and decision-boundary lab; Backpropagation graph walkthrough.

The instructor-administered, graded in-class variant at this module's end assesses equivalent skills:

  • Calculate an activation and a backward derivative.
  • Explain a gradient-based parameter update in a small network.
