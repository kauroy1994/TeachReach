Course modules

Stage 1

Symbolic Knowledge Representation

Stage overview →
01

Facts and predicates

Turn a lending request into named facts and say exactly which questions those facts can answer.

→02

Quantifiers and rules

Read statements about every borrower or at least one borrower, then apply a rule to the right person and item.

→03

Ontologies and knowledge graphs

Represent an inventory as a graph, use a class hierarchy to infer an item’s type, and follow a path to answer a request.

→04

Inference and proof traces

Derive a conclusion from a small set of rules and reconstruct the evidence and intermediate steps that support it.

→
Stage 2

Neural–Symbolic Architectures

Stage overview →
05

From a photograph to a symbolic claim

Explain what a learned score measures and decide which claim the desk can record from it.

→06

Connecting a neural detector to rules

Follow a photograph through a detector and a rule, then locate the first broken link in an incorrect recommendation.

→07

Teaching a model with examples and constraints

Fit one neural weight by hand and explain precisely how adding a desk rule changes the chosen value.

→08

Choosing predictions that satisfy constraints

Construct the allowed assignments, select the one with the highest total score, and explain what happens when no complete assignment is possible.

→
Stage 3

LLMs and Knowledge-Grounded Reasoning

Stage overview →
09

Finding evidence in text and graphs

Find the records needed to answer where Ava should pick up camera C1, and explain why each record belongs in the answer.

→10

Checking a language model’s claims

Break a generated answer into individual claims and classify each claim using records for the correct item and time.

→11

Building and checking a plan

Trace a plan from its starting facts to a goal, find the first step that cannot run, and repair the order when possible.

→12

Answering with evidence and knowing when to stop

Answer an eligibility question using a stated desk rule, cite the evidence for each requirement, and explain exactly what would resolve a missing or conflicting record.

→
Stage 4

Trustworthy and Applied Neurosymbolic AI

Stage overview →
13

Reading event histories

Decide whether one request’s records support a required order of events, and explain how a missing or tied time limits the answer.

→14

Comparing an observation with an intervention

Tell an observed group difference from the effect of a change, and calculate both in a small staffing model.

→15

Explaining and testing a hybrid decision

Trace a screening decision, compare a learned model and a rule on the same held-out requests, and locate an error using independent evidence.

→16

Capstone: auditing a hospital teaching-room handoff

Build and test an evidence-backed review of training-room equipment handoffs, then explain when an administrative reviewer needs to inspect the records.
