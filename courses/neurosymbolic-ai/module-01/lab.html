Explore a case

One request

The record contains Requested(Ava, C1) and Available(C1).

Which item did Ava request? What evidence would establish a completed loan?

Reveal the result and reasoning

Ava requested C1. Availability says the item is available in the record. A recorded handoff to Ava would establish the completed transfer.

Second borrower

Keep both original facts and add Requested(Bo, C1).

What does the query Requested(person, C1) return now?

Reveal the result and reasoning

It returns both Ava and Bo. Each name fills the blank in a different matching fact. Neither request alone gives an order for allocating C1.

Explicit status

The record contains Requested(Ava, C1) and Unavailable(C1). It says nothing about C2.

What can the desk tell Ava about C1 and C2?

Reveal the result and reasoning

The desk has a recorded reason to report C1 unavailable. C2’s status is unknown. It would need a status record for C2 before offering it as an available alternative.
