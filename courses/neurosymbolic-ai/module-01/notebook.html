Turn a lending request into named facts and say exactly which questions those facts can answer.

What can the desk tell Ava?

Ava sends a campus equipment desk a note asking for camera C1. A learned language model might help identify the item in a note. A symbolic system can then ask precise questions about the named item and the desk’s records. A neurosymbolic system connects those two kinds of work. We begin at the desk, after someone has read the note.

Our fictional desk records “Ava requested C1.” A request and a handoff are different events. What would you need to know to say Ava has the camera?
requests = [("Ava", "C1")]
print(("Ava", "C1") in requests)
Reveal the output
True

If the membership test prints True, what has the desk established?

Reveal the reasoning

It has found an entry for Ava’s request for C1. To say she has received the camera, we would also need evidence of a handoff.

Give each claim a name

A predicate names a property or relationship and tells us which positions to fill. Available(item) takes one item. Requested(person, item) takes a person and an item, in that order. Filling all the positions gives a statement we can ask about or record as a fact.

Requested(Ava, C1) says who requested which item. In Python we can keep the predicate name and its values together in a tuple, an ordered group in parentheses. Quotation marks mark names as text.
fact = ("Requested", "Ava", "C1")
predicate, person, item = fact
print(person, predicate.lower(), item)
Reveal the output
Ava requested C1

The note says “C1 was requested by Ava.” Which position should C1 occupy in Requested?

Reveal the reasoning

C1 is the second argument, the item. The wording of the note changed, but Ava still fills the person position.

Ask a question with a blank

A record can answer more than a yes-or-no question. In Requested(Ava, x), x is a variable, a placeholder for an item. Look for records whose person is Ava and read the item from each match.

With two requests by Ava and one by Bo, “What did Ava request?” has two answers. Each answer names an item that makes the statement match a record. The Python loop visits each person–item pair.
requests = [("Ava", "C1"), ("Bo", "T2"), ("Ava", "M1")]
for person, item in requests:
    if person == "Ava":
        print(item)
Reveal the output
C1
M1

How would you answer “Who requested C1?” with these same records?

Reveal the reasoning

Fix the item as C1 and read the person from each match. Only the first row has that item, so the answer in this record is Ava.

Leave room for an unknown

A desk record can be incomplete. In an open-world reading of the record, a missing fact leaves the corresponding claim unknown. A recorded negative claim can provide evidence against it. Python’s membership test answers a narrower question about what is in a collection.

C1 has an available label, and T2 has an unavailable label. Nothing in the record settles M1’s status. The Python dictionary pairs each recorded item with its status. Its get method supplies a default for a missing key.
status = {"C1": "available", "T2": "unavailable"}
for item in ["C1", "T2", "M1"]:
    print(item, status.get(item, "unknown"))
Reveal the output
C1 available
T2 unavailable
M1 unknown

A note says that Bo requested M1. What does that change about M1’s availability?

Reveal the reasoning

It adds a request. Availability is a separate claim, so M1’s availability remains unknown until there is evidence about that claim.

Find the items in Ava’s requests

The loop opens each pair into two names, person and item. The double equals sign asks whether the person in this row is Ava. Only the indented print line runs when the names match, so the two matching items appear on separate lines.

requests = [("Ava", "C1"), ("Bo", "T2"), ("Ava", "M1")]
for person, item in requests:
    if person == "Ava":
        print(item)

Question 1

Translate “Bo requests tripod T2” into a predicate and explain the two positions.

Hint

Reuse the same relationship used for Ava.

Reveal the worked answer

Requested(Bo, T2). Bo is the requester in the first position and T2 is the item in the second.

Question 2

A record contains Requested(Ava, C1), Requested(Ava, C2), and Requested(Bo, C2). Which question returns Ava and Bo as its answers?

Hint

Keep one item fixed and leave the requester blank.

Reveal the worked answer

Ask Requested(person, C2). The second and third facts match C2. Reading their person positions gives Ava and Bo.

Question 3

A clerk finds no record of Returned(Ava, C1) and concludes that Ava still has C1. Give two different histories consistent with the missing record.

Hint

Think about what has been recorded separately from what happened.

Reveal the worked answer

Ava might still have C1, or she might have returned it before the clerk entered the return. A missing return record alone cannot distinguish those histories.
