Correct. C1 supplies a witness. Its type places it in Equipment and its own location edge leads to Drawer3.

End-of-module exercises

Try each question before opening the hint or worked answer. The in-class variant asks you to apply the same skills to a new case. Assessment details →

Question 1

Encode “Ava requested C1, a camera stored in Cabinet7” as three triples.

Hint

Choose an edge for the request, one for the type and one for the location.

Reveal the worked answer

(Ava, requested, C1), (C1, type, Camera), and (C1, storedIn, Cabinet7). Reusing C1 allows another query to connect the three facts.

Question 2

The inventory adds a projector P3 without linking the Projector class to Equipment. Which general statement would support the inference that any projector is equipment?

Hint

One statement about the class can cover P3 and future projectors.

Reveal the worked answer

Record Projector as a subclass of Equipment. From P3 has type Projector, the class rule then yields P3 has type Equipment.

Question 3

Design a graph query that returns everyone who requested an item stored in Cabinet7. Which name has to match twice?

Hint

Work backward from the cabinet or forward from a request.

Reveal the worked answer

Match (person, requested, item) and (item, storedIn, Cabinet7). The same item fills the end of the first edge and the start of the second. Return the matching person.
