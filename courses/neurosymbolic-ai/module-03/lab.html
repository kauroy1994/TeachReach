Explore a case

One class step

C1 has type Camera. Camera is a subclass of Equipment.

Which type for C1 follows by the subclass rule?

Reveal the result and reasoning

C1 has type Equipment. The rule applies to individual members of Camera, and C1 is one of them.

A longer hierarchy

C1 has type MirrorlessCamera. MirrorlessCamera is a subclass of Camera. Camera is a subclass of Equipment.

What extra work is needed to reach Equipment for C1?

Reveal the result and reasoning

Apply the membership rule twice. The first application gives C1 type Camera. That newly inferred type supplies the starting point for the second application, which gives C1 type Equipment.

A broken path

The graph says Ava requested C1, Bo requested C2, and C2 is stored in Cabinet2.

For whose request can staff find the item’s storage cabinet?

Reveal the result and reasoning

Bo’s path runs through C2 to Cabinet2. Ava’s reaches C1 and stops. A storedIn edge beginning at C1 would let the desk answer her location question.
