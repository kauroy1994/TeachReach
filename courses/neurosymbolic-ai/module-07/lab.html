Explore a case

Train with labels alone

A has rim = 1 and cap target 0. Candidate weights are 0, 0.2, 0.4, 0.6 and 0.8. The rule penalty weight is zero.

Which weight minimizes the objective?

Reveal the result and reasoning

Weight 0 gives score 0 and label loss 0. Every larger candidate has a positive label loss. B carries no weight in this objective.

Compare two updates

Use equal costs, A's target 0 and B's verified minimum 0.8. Both have rim = 1. Compare candidate weights 0.4 and 0.6.

Which candidate better fits the combined evidence?

Reveal the result and reasoning

At 0.4 the total is 0.16 + 0.16 = 0.32. At 0.6 it is 0.36 + 0.04 = 0.40. The lower total selects 0.4.

Inspect a changed input

Keep the fitted weight 0.4. A fresh photo C has rim = 0 and independently verified cap presence.

What does this unit predict, and what penalty does the same rule assign?

Reveal the result and reasoning

The score is max(0, 0.4 × 0) = 0. The shortfall is 0.8, giving a penalty of 0.64. Any weight multiplied by this zero feature gives zero, so a weight change alone cannot fix this case.
