Where does the language model actually run in these examples?

The first example builds the prompt you could give an LLM. The lesson then supplies a sample draft and its individual claims. The Python cells run the evidence checks. Holding the draft fixed lets two students inspect the same mistake. In a working system, a model could receive the question and retrieved passages and produce the draft.

Can a checker always decide support by comparing strings?

Our records use agreed names, so equality is enough for these examples. Real sources might say “collect” where a draft says “pick up”. Someone must map those expressions to the same meaning and check details such as item and date before trusting the match.
