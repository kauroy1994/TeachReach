Explore a case

Start with orientation

Start with available and oriented. Reserve needs available, exchanges available for reserved. Issue needs reserved and oriented, exchanges reserved for issued. Try reserve then issue.

Which states do you visit?

Reveal the result and reasoning

Start with available and oriented. Reserve leaves oriented and reserved. Issue leaves oriented and issued. The goal is reached.

Reverse the proposed order

Use the same two actions and start with available and oriented. Try issue then reserve.

What is the first missing fact?

Reveal the result and reasoning

Issue checks for reserved and oriented. Only oriented is present. Stop at issue with reserved missing. The second action never runs.

Change the starting facts

Start with available only. Reserve needs available and creates reserved. Issue needs reserved and oriented. Try both orders.

Can reordering these two actions reach issued?

Reveal the result and reasoning

No. Issue first lacks both reserved and oriented. Reserve first supplies reserved, but neither action adds oriented. The desk needs evidence of orientation or an authorized action that completes it.
