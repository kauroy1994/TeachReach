Why bother with a process if a knowledge graph can store both actions?

A graph can represent when an event happened and which request it concerns. Those details let you ask whether a particular check preceded a particular handoff. A graph containing only the broad facts “Ava was checked” and “C1 was handed over” cannot answer that question about R7.

If I see the check first and the handoff second, did the check cause the handoff?

The log supports a statement about sequence. To ask about a cause, imagine changing whether the check happened and ask what that change would do to the outcome. A log of one sequence observes only what actually happened.
