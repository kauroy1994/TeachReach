How to start

Start with Module 01. You will need to read a short table and follow simple arithmetic. The first lesson introduces the logic notation. Each notebook shows the Python input and its output side by side. Use Colab or a local Python 3 notebook to change the examples.

Read the cells in order. A pair of values in parentheses keeps its order, a list groups entries, and print shows the result of a calculation. The core notebooks use the Python standard library. Two extension notebooks introduce PyTorch training and generation with a downloaded language model.

Course outcomes

  • Represent a situation using facts, quantified rules and a knowledge graph. Trace a conclusion to its premises.
  • Connect a learned score to a symbolic decision. Compare a training penalty with a constraint applied when choosing an output.
  • Retrieve records, verify individual claims, and trace a plan from its starting facts to its goal.
  • Evaluate a hybrid system on held-out cases, distinguish a causal assumption from an observation, and explain an administrative decision using source records.

Practice and assessment

In each module, predict a result before revealing its explanation. Use the lab to change the evidence, then try the exercises on a fresh case. The practice is formative. At the end of each module, the instructor grades a separate in-class variant. You will solve a new case using the same skills and explain your reasoning.

A complete answer identifies the relevant inputs, applies the rule or model correctly, and states what the evidence supports. In the capstone, also test a boundary case and explain an error against a reference judgment.

CS 691 at the University of Alabama

Kaushik Roy taught CS 691 as a graduate special-topics course in Spring 2026. Nigel Glenday and Raj Krishnan were guest lecturers. This TeachReach edition develops the four published topic groups into a new sequence of worked lessons, practice cases, and notebooks.

Research connected to the course

In their NeSy 2026 paper, Himanshu Tripathi, Kaushik Roy, Subash Neupane, and Shahram Rahimi use a language model to normalize clinical terms and a fuzzy rule system to evaluate documented events. Stage 4 asks you to trace what happens when a term is mapped incorrectly.
